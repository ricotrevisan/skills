# Rubric

Built from the Defacto site climb (PRs #260 and #262) and the brussels.wtf reader climb (#166). Each criterion is scored 0–100.

| Score | Meaning |
|---|---|
| 90+ | As good as the best product in its class |
| 80 | Ship quality, no flaw a user would notice |
| 70 | Works, but has visible flaws |
| 50 | Gets in the user's way |
| <40 | Broken or missing |

## Criteria

Score every **core** criterion. Then add **marketing** criteria for public pages that sell something, and **app** criteria for screens a signed-in user works in. Write the chosen list into `climb.md` and leave it unchanged for the rest of the climb.

### Core

| Key | Question |
|---|---|
| `task_flow` | Can a first-time user finish the key tasks without hesitating? Score it from the walk logs: steps taken, dead ends, unclear controls and missing feedback. |
| `message` | Can a newcomer tell what this is and what to do here within 5 seconds? |
| `content_design` | Are labels, headings and microcopy plain, specific and short? |
| `hierarchy_layout` | Does the eye land on the most important thing first? Do grouping and spacing show how things relate? |
| `typography` | Is the type readable, with a consistent scale, measure and rhythm? |
| `imagery_iconography` | Do the icons, images and logo carry meaning and look like one set? |
| `color_brand` | Does colour carry state and emphasis on purpose, with a recognisable identity? |
| `consistency` | Do the same things look and behave the same across screens? |
| `motion_feedback` | Does every action get a visible response, with purposeful motion? |
| `responsive` | Does every screen work at 320px and at 1440px, with no clipping, overflow or wasted space? |
| `accessibility` | Are contrast, 44px targets, focus visibility, colour-free states and text size all right? |
| `distinctiveness` | Does it look like this product and not a template? |

### Marketing

| Key | Question |
|---|---|
| `narrative_proof` | Does the story build trust with specific, true proof? |
| `conversion` | Is the next step obvious and repeated where intent peaks, with its cost stated? |

### App

| Key | Question |
|---|---|
| `structure_flow` | Are navigation and wayfinding clear? Does the user always know where they are and how to go back? |
| `trust` | Are data, sources and system state shown honestly, without doubt about what was saved? |
