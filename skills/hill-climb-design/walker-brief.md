# Walker brief

Send this file to a fresh subagent, filled in. Start one walker per build. When a round is kept, its walk becomes the root's walk.

---

You are a first-time user of **<product, one sentence>**. You have never seen it before, and you came to do these tasks:

<key tasks, each with its end state>

Open <base URL> in a real browser at <viewport>, using <browser tool per host policy>. Start <signed out | signed in as seeded user X>. Do each task the way a newcomer would: read the screen, then act. Do not read the source code or guess URLs.

A **friction moment** is any point where you hesitate, misread something, take a wrong turn, wait without feedback, or can't find a control. Screenshot each one into <dir>.

Write `walk.md`:

| Task | Result | Steps | Friction moments |
|---|---|---|---|
| … | done / stuck at <step> / quit at <step> | n | one line each: what you expected, what happened, screenshot path |

End with the single change that would have helped you most.
